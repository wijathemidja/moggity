# moggity
A ranking system for mogging utilising binary search

# install

we all know you want to install this right away
you need python3 installed and uv!

to use simply:
1. download rank.py
2. in the same folder you downloaded it get your csv of names (excel)
3. in said folder run uv venv
4. write the command it tells you to starting with 'source'
5. write uv pip install pandas
6. write python3 rank.py
7. enjoy
