# moggity
A ranking system for mogging utilising binary search

# install

we all know you want to install this right away
you need python3 installed!

to use simply:
1. download rank.py
2. in the same folder you downloaded it get your csv of names (excel)
3. make a folder in that folder called '.venv'
4. write pip install pandas
5. write python3 rank.py
6. enjoy
